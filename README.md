# SoireeMusicPack
The Soirée music pack for Balatro as a [Steamodded](https://github.com/Steamodded/smods) (REQUIRED) mod 
## Installation
After installing Steamodded on Linux, clone the repository in Lua with `git clone https://github.com/Undercoverer/SoireeMusicPack.git` into the mods directory created with the Steamodded installation.
For Windows, download [Windows Visual Studio](https://visualstudio.microsoft.com/) and clone the repository with the software.
